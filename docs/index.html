开始使用

安装序页

选择对应浏览器的 ZIP，解压后从扩展管理页加载。

  1. 下载安装包，解压到一个长期保留的文件夹。
  2. Chrome 打开 chrome://extensions/；Edge 打开 edge://extensions/，开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
  4. 打开新标签页即可使用，安装后保留解压文件夹。
